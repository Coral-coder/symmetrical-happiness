Install as an app

Homebrew Vault works offline and can be installed like a normal app:

  • Windows: in Edge or Chrome, use the Install app button at the top (or the install icon in the address bar).
  • Android: in Chrome, open the ⋮ menu and choose Add to Home screen → Install. Then you can Share any webpage to Homebrew Vault to import it.
  • iPhone / iPad: in Safari, tap Share → Add to Home Screen.

Bookmarklet

Some sites (D&D Beyond, for example) won't let other pages read them. The bookmarklet gets around this: open the page you want, click the bookmark, and it sends that page straight into the importer.

Import proxies

Webpages are fetched directly when the site allows it. Otherwise, they go through these public CORS proxies, tried in order. {url} is replaced by the page address. Pages you import are sent to these services.

Free public proxies are often rate-limited or down. For reliable imports, host your own free one on Cloudflare Workers using proxy/cloudflare-worker.js (5-minute setup) and put its URL first in this list. The bookmarklet and Paste never need a proxy.
